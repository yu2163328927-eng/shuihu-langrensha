# 水浒传·梁山卧底 V5 沉浸版

基于《水浒传》的单文件互动推理游戏：你受晁盖密命出任梁山"掌案头领"，七夜之内查出寨中官府暗桩——不能错杀一个兄弟。

在线版：<https://yu2163328927-eng.github.io/shuihu-langrensha/>

下载游戏目录中的 `水浒狼人杀.html` 后双击即可离线游玩。

## 特色

- **七夜七案**：黄泥冈、济州、石碣村、断金亭、兵器库、聚义厅、忠奸终审，场景呼应原著
- **证据四维系统**：来源 / 完整度 / 独立性 / 可核验性，不直接公布真假
- **15 名原著好汉**：吴用、公孙胜、林冲、鲁智深、武松、杨志、白胜……性格与台词取自原著
- **三种模式**：经典 / 无间 / 铁案；12 种结局 + 结局图鉴与新案传承
- **好汉同行特技**：调查时可带一名好汉同行，按性格获得不同加成
- **每夜随机风波**：10 种突发事件，处理得当可获资源或线索
- **程序合成古风 BGM**（五声音阶）与合成音效，音量可调
- **存档系统**：自动存档 + 3 个手动档位 + 导出/导入存档文件（可跨设备、跨网页版与桌面版迁移）
- 移动端触控优化，全平台可用
